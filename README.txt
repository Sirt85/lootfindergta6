GTA VI Loot Finder – Android-Projekt
1. Android Studio installieren (developer.android.com/studio).
2. ZIP entpacken und den Ordner LootFinder öffnen.
3. Gradle-Synchronisierung abwarten, ggf. Android SDK 35 installieren und Gradle JDK 17 oder 21 wählen.
4. Build > Generate App Bundles or APKs > Generate APKs (je nach Version Build APK(s)).
5. app/build/outputs/apk/debug/app-debug.apk auf das Handy kopieren und installieren.
Die Karte stammt aus deinem Upload. Fundorte werden selbst gesetzt, da keine verifizierten Koordinaten vorliegen. Fortschritt wird lokal gespeichert; Deinstallation kann ihn löschen. Keine Internetberechtigung. Projekt wurde nicht als APK kompiliert oder auf Android getestet. Die HTML-Datei kann auch im Browser ausprobiert werden, sofern map.jpg daneben liegt.
